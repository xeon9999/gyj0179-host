一、这次改了什么
================================================================

1) 单片机固件 (chengxu.c)
   - 从站地址、波特率改成"上位机可修改 + 掉电保存(EEPROM)"
   - 开机在全部 7 档波特率上轮流广播本机地址/波特率，便于找回
   - 多台同时上电时按地址错开广播时刻，避免总线撞车
   - 广播结束后清空接收缓冲，避免残留数据被误当 Modbus 请求
   - 编译结果：0 错误 0 警告，code 5268 字节（8KB 的 64%）

2) 上位机
   - 新增 ⚙ 通信配置：在线改从站地址/波特率，自动重连
   - 新增 📡 监听上报：即使地址/波特率被改错也能找回设备
   - 新增 ■ 停止扫描：扫描可随时人工中止
   - 新增 🔄 刷新串口：USB 重新插拔后 COM 号变化时可刷新
   - 保持寄存器列表里 reg[13]/reg[14] 显示固定名称
   - 波特率表补齐为 7 档，与固件完全一致（原来只有 5 档）


================================================================
二、寄存器约定（固件与上位机一致）
================================================================

  reg[0..12]  原有参数寄存器，用法不变
  reg[13]     从站地址      读写   1~247（写 0x00FF = 恢复默认）
  reg[14]     波特率索引    读写   0~6（见下表）
  reg[15]     配置命令      只写   见下表

  波特率索引表（晶振 11.0592MHz，定时器2 作波特率发生器）
      0 → 9600     1 → 19200    2 → 38400    3 → 57600
      4 → 115200（默认）        5 → 28800    6 → 14400

  命令寄存器 reg[15]
      0x5AA5   保存参数到 EEPROM（兼容旧用法）
      0xA500   保存并立即应用新地址/波特率（不断电、不复位）
      0xA501   恢复出厂设置（地址 0x02、波特率 115200）并保存

  写入方式：用功能码 0x06 逐条写  地址 → 波特率 → 命令
            （实测本板 0x10 写多个寄存器应答不稳定）

三、上位机操作
================================================================

3.1 ⚙ 通信配置（改了地址/波特率）
  1. 先"扫描并连接"上从站
  2. 点"⚙ 通信配置"，窗口会读回当前 从站地址 / 波特率
  3. 改成目标值 → 点"应用并保存到从站" → 确认
  4. 之后全自动：等约 2 秒 → 配置窗口自动关闭 → 主界面自动扫描重连
  5. 改错连不上：用下面的"📡 监听上报"找回，或点窗口里"恢复出厂"

3.2 📡 监听上报（地址/波特率改错后找回设备）
  1. 点"📡 监听上报"，选串口（列表会自动刷新，自动跳过蓝牙口）
  2. 点"开始监听"
  3. 给板子断电，再重新上电（或按复位）
  4. 收到后显示：★ 收到上报: 地址=X 波特率索引=i (nnnnnbps)
  5. 点"使用该参数扫描"→ 自动填地址、波特率设"自动"、范围扩大 → 自动连接
  注意：监听期间本窗口独占串口；若 20 秒内没收到会给出排查提示。

3.3 ■ 停止扫描
  扫描（尤其单站的"全地址搜索"可能几分钟）可随时点停止，
  最迟当前一次探测结束就退出，实测 0.07 秒内响应。

3.4 🔄 刷新串口
  重新插拔 USB 后 CH340 的 COM 号会变（例如 COM6 → COM11），
  点一下刷新；上位机里选错端口会表现为"完全连不上"。

  第 2 步  接线检查（这次烧板子的教训，务必确认）

           - 确认 A/B 对应（接反会导致收发全不通）
           - 板子 GND 与 USB 转 485 模块 GND 必须共地
           - 建议换用"隔离型"485 模块，能挡住地电位差与浪涌

  第 3 步  验证固件在上报（不依赖上位机）
           关闭上位机，运行：E:\Chatbox AI\485\监听上报.py
           看到 ">>> 现在请给板子断电, 再重新上电 <<<" 后断电上电
           预期打印：★ 收到上报: GYJ0179 ADDR=0x02 INDEX=4 BAUD=115200
           （默认地址 2 / 115200；如果你以前改过，这里会显示改后的值）

  第 4 步  上位机连接
           打开单站或多站 GUI → 串口选 CH340 那个口（先点🔄刷新）
           → 地址范围 1~247 → 波特率选"自动" → 点"扫描并连接"

  第 5 步  验证新功能
           - ⚙ 通信配置：应正确显示当前地址与波特率（不是"配置无效"）
           - 改一次地址（例如 2 → 6）→ 应用 → 应自动关窗并自动重连到 6
           - 📡 监听上报：断电上电应能收到上报

五、硬件故障参考（这次的排查结论）
================================================================

  现象 → 结论对照：
    T 灯上电闪烁                → 单片机在发送（固件正常）
    R 灯扫描时不闪              → 电脑的请求没到单片机
    监听 7 档波特率收不到任何字节 → 线路上没有有效差分信号
    485 芯片发烫                → 收发器已损坏（内部击穿/过流）

  排查要点：
    1. 用万用表量 A-B 之间电阻：正常几十 kΩ 以上（带 120Ω 终端约 120Ω），
       接近 0Ω 说明芯片已短路击穿
    2. 量 A/B 对 GND 是否短路
    3. 自检 485 模块：把模块的 A、B 短接到它自己，上位机扫描能自收自发，
       说明适配器与电脑侧正常，问题在板子侧
    4. 换隔离型 485 模块，避免再次烧毁
